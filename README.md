# AI Service Management Platform

Учебная корпоративная платформа управления заявками и инцидентами.

Проект создается как практическая лаборатория для изучения backend-,
API-, интеграционного и автоматизированного тестирования.

## Бизнес-задача

Сотрудники компании должны иметь возможность создавать обращения
о технических проблемах, отслеживать их состояние и получать
уведомления об изменениях.

В следующих версиях AI-модуль будет автоматически определять
категорию, приоритет и ответственную команду.

## Реализовано в версии 0.1.0

- создание заявок;
- получение списка заявок;
- получение заявки по идентификатору;
- фильтрация по статусу;
- изменение статуса;
- удаление заявки;
- позитивные и негативные API-тесты.

## Технологии

- Python
- FastAPI
- Pydantic
- pytest
- HTTPX
- OpenAPI / Swagger
